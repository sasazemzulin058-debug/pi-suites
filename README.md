# pi-suites

Unified precompiled extension suites for [Pi Coding Agent](https://github.com/badlogic/pi-mono), optimized for Termux/Android ARM64.

## Suites
- `pi-search-suite`: Bundles `pi-lens`, `pi-readseek`, `pi-shazam`, `pi-web-access`, `fff-node`.
- `pi-memory-suite`: Bundles `pi-hermes-memory`, `context-mode`.
- `pi-execution-suite`: Bundles `@quintinshaw/pi-dynamic-workflows`, `pi-subagents`, `@aliou/pi-processes`, `pi-schedule-prompt`, `pi-loop-police`.
